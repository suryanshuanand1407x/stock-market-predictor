# Stock Market Prediction Project

## Overview
This project aims to predict stock market trends using machine learning algorithms based on historical SENSEX data.

## Project Structure

## Setup
1. Clone this repository
2. Install required dependencies
3. Place your SENSEX data in the `data` directory

## Usage
1. Data Preprocessing:
   ```
   python scripts/preprocess.py
   ```

2. Model Training:
   ```
   python scripts/train.py
   ```

3. Making Predictions:
   ```
   python scripts/predict.py
   ```

## Dependencies
- Python 3.8+
- pandas
- numpy
- scikit-learn
- tensorflow/pytorch
- matplotlib
- seaborn
