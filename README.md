# Stock Market Prediction Project

## Overview
This project aims to predict stock market trends using machine learning algorithms based on historical SENSEX data.

## Setup
1. Clone this repository.
2. Install required dependencies.
3. Place your SENSEX data in the `data` directory.

## Dependencies
- Python 3.8+
- pandas
- numpy
- scikit-learn
- tensorflow/pytorch
- matplotlib
- seaborn

## Usage
1. Run the `preprocess.py` script to clean and prepare your data.
2. Use `train.py` to train the model with your dataset.
3. Execute `predict.py` to make predictions based on the trained model.
